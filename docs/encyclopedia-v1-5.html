الدليل المرجعي / نسخة 1.2

من الفكرة إلى الفيديو، ومن الجهاز إلى المنصة

موسوعة المشروع / البداية وفكرة المشروع

البداية وفكرة المشروع

اضغط على أي عنوان لقراءة التفاصيل، ويمكنك فتح جميع الفروع أو إغلاقها.

ما هو حين تنطق الصور؟+
برنامج محلي لإنشاء فيديوهات اعتمادًا على النصوص والصور والمقاطع والصوت. الواجهة التي فتحناها تحمل اسم «حين تنطق الصور v1.3.0»، وهي نسخة عربية مبنية على MoneyPrinterTurbo. لا يعني تشغيل الواجهة وحده أن كل خدمات التوليد تعمل دون إعداد إضافي.
ما الذي تحقق بالفعل؟+
تم إنشاء بيئة Python 3.11، وتثبيت الحزم من requirements.txt، ونجح فحص pip check، وبدأ خادم Streamlit على المنفذ 8501، وظهرت الواجهة العربية. لم ننفذ بعد إنتاج فيديو كامل.
ما الذي لم نختبره؟+
التوليد الفعلي للفيديو، اختيار محرك التعليق الصوتي، دمج الوسائط، نجاح التصدير، وصلاحية مفاتيح الخدمات الخارجية. هذه أمور تحتاج إلى اختبار منفصل.
موسوعة المشروع / هيكل المشروع وملفاته

هيكل المشروع وملفاته

اضغط على أي عنوان لقراءة التفاصيل، ويمكنك فتح جميع الفروع أو إغلاقها.

main.py+
ملف Python رئيسي في جذر المشروع؛ يلزم فحص محتواه لتحديد دوره الدقيق عند التشغيل.
webui و webui.bat+
مجلد واجهة المستخدم وملف تشغيل Windows. نجح تشغيل واجهة Streamlit بالأمر python -m streamlit run webui\Main.py.
app+
مجلد منطق التطبيق؛ تفاصيل وحداته الداخلية لا يمكن الجزم بها من أسماء المجلدات وحدها.
requirements.txt+
قائمة حزم Python المطلوبة. قرأها pip وثبّت المتطلبات بنجاح.
config.toml+
ملف الإعدادات الذي ظهر في سجل التشغيل أنه تم تحميله. قد يتضمن إعدادات خدمات؛ تجنب نشر أي مفاتيح أو أسرار منه.
pyproject.toml و uv.lock+
ملفات توصيف المشروع وقفل إصدارات الحزم المرتبطة بأداة uv؛ وجودها لا يعني وجوب استخدامها بدل البيئة التي جهزناها.
docs / resource / storage / test+
مجلدات تشير أسماؤها إلى الوثائق والموارد والتخزين والاختبارات؛ يجب فحص محتوياتها لتحديد الاستخدام الدقيق.
.venv+
بيئة Python معزولة أنشأناها محليًا. لا تُرفع إلى GitHub؛ يمكن إعادة إنشائها من ملفات المتطلبات.
README-ar.md و README-GIDO-AR.md+
ملفات إرشادية عربية موجودة بحسب قائمة الملفات، وهي أول مصادر ينبغي مراجعتها لفهم خصائص هذه النسخة.

المكتبات البرمجية

اضغط على أي عنوان لقراءة التفاصيل، ويمكنك فتح جميع الفروع أو إغلاقها.

ما معنى تثبيت المكتبات؟+
المكتبة مجموعة شيفرات جاهزة لتنفيذ مهام محددة. تثبيتها داخل .venv يجعل البرنامج قادرًا على استدعائها دون إعادة كتابة وظائفها من الصفر.
Streamlit+
إطار لبناء واجهة تفاعلية تعمل في المتصفح. ظهر في تشغيل واجهتنا المحلية.
MoviePy و imageio-ffmpeg+
أدوات للتعامل مع الفيديو والصوت والتجميع؛ وجود الحزمة لا يثبت نجاح معالجة كل صيغة فيديو على جهازك.
faster-whisper+
مكتبة للتعرف على الكلام وتحويله إلى نص، وقد تحتاج إلى تنزيل نموذج عند الاستخدام.
edge-tts+
مكتبة لتحويل النص إلى كلام عبر خدمة صوتية؛ قد تحتاج اتصالًا بالإنترنت، وليست محركًا صوتيًا مستقلًا يعمل بالكامل دون شبكة.
arabic-reshaper و python-bidi+
أدوات لمعالجة تشكيل الحروف العربية واتجاهها عند عرض النص في بيئات رسومية.
openai و google.generativeai+
عملاء للتواصل مع خدمات نماذج خارجية؛ مجرد تثبيتها لا يفعّل API ولا يمنح رصيدًا مجانيًا.
pip check+
فحص تعارضات تبعيات الحزم؛ ظهور No broken requirements found لا يضمن أن كل وظائف البرنامج ستعمل عند التشغيل.

شرح الواجهة العربية

اضغط على أي عنوان لقراءة التفاصيل، ويمكنك فتح جميع الفروع أو إغلاقها.

الإعدادات الأساسية+
تظهر مزود الذكاء الاصطناعي OpenAI واسم النموذج gpt-4o-mini وحقول API، إضافة إلى مفاتيح مصادر الوسائط. لا تُدخل مفاتيح مدفوعة قبل تحديد الحاجة إليها.
إعدادات النص العربي+
تحتوي على الفكرة أو وصف الصورة، أمثلة عربية، لغة النص ar-SA، إعدادات نص متقدمة، ونص التعليق الصوتي.
إعدادات الفيديو+
تظهر مصدر الوسائط المحلي، رفع صور أو فيديو، ملاءمة الصور، حركة الصور، ترتيب المقاطع، الانتقالات، ومقاس عمودي 9:16.
إعدادات الترجمة+
تتيح إظهار النص على الفيديو واختيار خط مثل STH eitiMedium.ttc كما ظهر في الواجهة، والموضع والحجم والألوان وخلفية النص.
ما الذي ينبغي فحصه لاحقًا؟+
الإعدادات المتقدمة للنص والصوت، خيارات التصدير، وأي تبعيات تشغيل إضافية مثل FFmpeg أو نماذج صوتية.
موسوعة المشروع / رحلة إنتاج فيديو

رحلة إنتاج فيديو

اضغط على أي عنوان لقراءة التفاصيل، ويمكنك فتح جميع الفروع أو إغلاقها.

1 — تحديد الفكرة+
اختر رسالة قصيرة ومشهدًا واحدًا للتجربة الأولى، مع نص تعليق صوتي جاهز لتجنب الحاجة إلى توليد نص خارجي.
2 — اختيار الوسائط+
اختر «ملف محلي من جهازك» وارفع صورة أو مقطعًا تملك حق استخدامه.
3 — ضبط الحركة والمقاس+
اختر حركة خفيفة ومقاس 9:16 لفيديو عمودي؛ لا تفترض أن الحركة متاحة قبل اختبارها.
4 — إعداد الصوت والنص+
اختر صوتًا عربيًا مناسبًا بعد فحص إعدادات المحرك، واضبط موضع النص وحجمه.
5 — اختبار قصير+
نفّذ تجربة قصيرة، وراقب رسائل PowerShell لمعرفة الأخطاء أو المتطلبات الناقصة.
6 — مراجعة وتصدير+
افحص وضوح العربية، تزامن الصوت، جودة الصورة، وحجم الملف النهائي قبل اعتماد الفيديو.
الموسوعة / التشغيل والنقل بين الأجهزة

نقل الاستوديو إلى جهاز آخر — دليل التثبيت والتشغيل

دليل عملي لنظام Windows. صفحة HTML هذه مرجع محمول، وليست حزمة تثبيت. لتشغيل البرنامج على اللابتوب يجب نقل مجلد المشروع الكامل أو الحصول على نسخة مطابقة منه. لا يمكن استعادة التعديلات العربية الخاصة بمجرد تنزيل المستودع الأصلي.

1. قائمة الملفات التي يجب الاحتفاظ بها ونقلها+

انسخ المجلد الذي يحتوي فعليًا على requirements.txt وmain.py وwebui، وليس المجلد الذي يحتوي على .venv فقط. عندنا اسم مجلد الشيفرة الذي جرى تشغيله هو MoneyPrinterTurbo-main-studio-b1، لكن مكانه الكامل في Downloads قد يختلف.

  • app/ وwebui/: كود التطبيق والواجهة.
  • main.py وwebui/Main.py: نقاط الدخول حسب طريقة التشغيل.
  • requirements.txt: قائمة حزم Python.
  • config.toml: إعدادات البرنامج؛ قد يتضمن أسرارًا، فلا تشاركه علنًا قبل مراجعته.
  • resource/ وstorage/ وdocs/: الموارد والبيانات والمستندات؛ انسخ ما تحتاجه مع مراعاة الخصوصية.
  • webui.bat وREADME-ar.md وأي ملفات تخصيص أخرى: احتفظ بها.

لا يلزم عادةً نقل .venv/: أنشئ بيئة جديدة على الجهاز الآخر. تجنّب نقل ملفات الأسرار أو الفيديوهات الشخصية إلى GitHub عام.

2. البرامج اللازمة والروابط الرسمية+
  • Python لويندوز — الموقع الرسمي — استخدم Python 3.11 كما نجح معنا، وتحقق من توفر الأمر py -3.11.
  • Git for Windows — اختياري عند استخدام GitHub، وليس شرطًا لتشغيل النسخة المنقولة.
  • FFmpeg — صفحة التنزيل الرسمية — أداة معالجة الفيديو والصوت؛ قد تحتاجها بعض وظائف التصدير. اتبع تعليمات حزمة Windows وتحقق من ffmpeg -version.
  • المشروع الأصلي MoneyPrinterTurbo على GitHub — ليس بديلًا مؤكدًا عن النسخة العربية المعدّلة؛ استخدمه للمراجعة والمرجع فقط.
  • توثيق Streamlit — إطار الواجهة الذي يظهر الموقع المحلي.

تحتاج اتصالًا بالإنترنت لتنزيل البرامج والحزم أول مرة. وقد تحتاجه لاحقًا إذا استُخدمت خدمات صوت أو ذكاء اصطناعي خارجية.

3. تجهيز اللابتوب خطوة بخطوة+

أولًا: انقل مجلد المشروع كاملًا إلى مكان واضح مثل C:\VideoStudio\MoneyPrinterTurbo-main-studio-b1، وافتحه في مستكشف الملفات. من شريط العنوان اكتب powershell ثم Enter؛ ستظهر نافذة الأوامر السوداء في المجلد الصحيح.

ثانيًا: نفّذ الأوامر التالية واحدًا تلو الآخر (انسخها كما هي):

py -3.11 --version
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip check

النتيجة التي ظهرت لدينا سابقًا للفحص الأخير: No broken requirements found. وهذه علامة جيدة على سلامة الاعتماديات، لكنها لا تثبت نجاح تصدير الفيديو.

4. تشغيل النافذة السوداء وفتح واجهة الاستوديو+

من PowerShell داخل مجلد المشروع شغّل:

.\.venv\Scripts\python.exe -m streamlit run webui\Main.py

اترك نافذة PowerShell مفتوحة طوال استخدام الاستوديو. عندما يظهر عنوان Local URL: http://localhost:8501 افتح http://localhost:8501 على نفس الجهاز الذي يشغّل البرنامج. لا يعني هذا الرابط أن الاستوديو منشور على الإنترنت؛ كل جهاز له localhost الخاص به.

لإيقاف البرنامج، ارجع إلى النافذة السوداء واضغط Ctrl+C. إذا لم يفتح الموقع، تحقق أولًا من استمرار تشغيل الخادم ومن عدم استخدام المنفذ 8501 بواسطة برنامج آخر.

5. ملف تشغيل بنقرة واحدة (اختياري)+

يمكن إنشاء ملف نصي باسم start-studio.bat داخل مجلد المشروع ولصق هذا المحتوى فيه. ثم افتحه بالنقر المزدوج بعد اكتمال التثبيت:

@echo off
cd /d "%~dp0"
.venv\Scripts\python.exe -m streamlit run webui\Main.py
pause

هذا مجرد نموذج لإنشاء ملف تشغيل محلي، وليس ملفًا موجودًا أو مختبرًا على اللابتوب بعد. يمكن كذلك تجربة webui.bat الموجود في المشروع بعد مراجعة محتواه.

6. الأخطاء الشائعة وكيف تتجنبها+
  • requirements.txt غير موجود: أنت في المجلد الخطأ. ابحث عن المجلد الذي يحتوي webui وrequirements.txt معًا.
  • Python 3.11 غير معروف: ثبّت Python 3.11 ثم أغلق PowerShell وافتحه مجددًا.
  • ModuleNotFoundError: غالبًا لم يكتمل تثبيت المتطلبات أو شغّلت Python خارج .venv.
  • localhost لا يعمل: تحقق من رسالة التشغيل والمنفذ واحتفظ بالنافذة السوداء مفتوحة.
  • فشل إخراج الفيديو: افحص رسالة الخطأ، ومسارات الوسائط، وFFmpeg، وخدمات الصوت المستخدمة؛ لا تفترض أن نجاح فتح الواجهة يعني نجاح الإنتاج.
  • المفاتيح الخارجية: لا تنقلها في ملفات عامة، ولا تشترِ خدمات أو تستخدم API مدفوعًا دون قرار صريح.
7. ما الذي يُحفظ في GitHub وما الذي لا يُحفظ؟+

يمكن حفظ الشيفرة وملفات الدليل والتعليمات وملفات الإعداد النموذجية في مستودع خاص أولًا. لا ترفع .venv/ أو ملفات المفاتيح أو بيانات المستخدمين أو الوسائط الخاصة. يجب فحص config.toml وملفات .env قبل أي رفع. قاعدة البيانات ليست شرطًا لتثبيت البرنامج على جهاز آخر؛ تُضاف لاحقًا إذا احتجنا إدارة مشاريع ومستخدمين وسجل إنتاج.

8. قائمة تحقق بعد النقل — أول تشغيل ناجح+
  1. تأكد من وجود الملفات الأساسية في المجلد الصحيح.
  2. تحقق من Python 3.11.
  3. أنشئ .venv وثبّت requirements.txt.
  4. نفّذ pip check وتأكد من خلوه من تعارضات معروفة.
  5. شغّل Streamlit وافتح localhost:8501.
  6. تأكد من ظهور الواجهة العربية «حين تنطق الصور».
  7. جرّب صورة غير حساسة ونصًا عربيًا قصيرًا، وسجّل هل نجح تصدير MP4 بالفعل.

مهم: هذا الدليل لا يضم ملفات البرنامج نفسها داخل HTML، ولا يمكنه تثبيت Python تلقائيًا؛ لكنه يحتفظ بالخطوات والروابط وأسماء الملفات دون الحاجة إلى العودة إلى المحادثة.

الموسوعة / دليل تنفيذ موجه

ماذا تريد أن تُنتج؟

اختر المهمة، ثم اتبع الخطوات بالترتيب. الخطوات المقترحة للاختبار ليست ضمانًا لدعم الميزة.

ابدأ هنا — كيف تختار مسار العمل؟+
حدّد المدخلات أولًا: نص فقط، صورة واحدة، عدة صور، فيديو، أو ملف صوت. ثم اختر النتيجة: فيديو عمودي 9:16 أو أفقي 16:9، مع تعليق أو ترجمة أو موسيقى. لا تضف خدمات مدفوعة قبل التأكد من الحاجة إليها.
أريد فيديو من صورة واحدة مع تعليق عربي+
1. افتح الواجهة على localhost:8501 بعد تشغيل الخادم. 2. في «إعدادات النص العربي» اكتب فكرة واضحة ونص التعليق أو ولّده بالطريقة المتاحة. 3. في «إعدادات الفيديو» اختر «ملف محلي من جهازك» وارفع صورة JPG/PNG. 4. اختر «احتواء بخلفية سوداء» أو ملاءمة مناسبة، وحركة «تكبير بطيء». 5. اضبط اللغة والصوت والترجمة. 6. اختر الأبعاد ثم شغّل الإنتاج إن ظهرت أزراره، وراجع MP4. ملاحظة: لم نتحقق بعد من نجاح التصدير؛ قد تحتاج إلى ضبط محرك الصوت.
لدي عدة صور وأريد قصة مرئية+
1. حضّر الصور ورتّبها بالأسماء 01، 02، 03. 2. اكتب نصًا يقابل كل صورة أو مشهد. 3. جرّب رفع الصور دفعة واحدة من خانة الرفع المحلي؛ إن لم تسمح الواجهة بالتعدد، اختبر آلية المقاطع المتاحة ولا تفترض دعم الترتيب اليدوي. 4. اختر ترتيب المقاطع والانتقالات. 5. أضف التعليق والترجمة. 6. راجع الترتيب والتوقيت والتصدير.
أريد فيديو من فكرة ونص فقط+
1. أدخل الفكرة ونص التعليق. 2. اختر مصدر الوسائط المتاح في القائمة بدل الملف المحلي إذا رغبت في البحث عن لقطات. 3. جهّز مفاتيح المصادر فقط عند الحاجة وبعد التحقق من الترخيص. 4. اضبط الصوت والترجمة والأبعاد. 5. نفّذ تجربة قصيرة. استخدام مزود ذكاء اصطناعي خارجي قد يتطلب API برسوم مستقلة.
لدي فيديو وأريد إضافة تعليق وترجمة+
1. احتفظ بنسخة من الفيديو الأصلي. 2. اختر «ملف محلي» وارفع MP4 أو MOV ضمن حد الرفع الظاهر. 3. أدخل نص التعليق أو جرّب توليده. 4. فعّل الترجمة واضبط الخط والحجم والموقع. 5. اختبر بمقطع قصير أولًا. تنبيه: الحفاظ على الصوت الأصلي، وتعديل توقيت اللقطات، والتحرير الزمني التفصيلي وظائف غير مثبتة في النسخة الحالية.
أريد موسيقى خلفية أو أغنية+
1. افحص بقية خيارات الواجهة وملفات الإعداد لمعرفة هل يوجد حقل موسيقى أو رفع ملف صوت. 2. إن وُجد، جرّب ملفًا تملك حقوق استخدامه واضبط مستوى الصوت بالنسبة للتعليق. 3. إن لم يوجد، صدّر الفيديو ثم امزجه بمحرر خارجي. لا تفترض إمكانية إدخال رابط أغنية مباشرة أو استعمال أغنية محمية دون ترخيص.
أريد أن تتكلم الشخصية في الصورة وتحرك شفتيها+
هذه ليست حركة «تكبير بطيء» للصورة. تحتاج أداة متخصصة في تحريك الوجه ومزامنة الشفاه. المسار المقترح: إعداد الصورة والنص والصوت → إنشاء لقطة ناطقة بأداة متخصصة → استيراد الناتج كفيديو محلي إن كان المسار مدعومًا → إضافة ترجمة وتصدير. لم نثبت وجود ميزة تحريك الشفاه داخل MoneyPrinterTurbo.
أريد إعلانًا قصيرًا أو فيديو يوتيوب+
1. حدّد الجمهور والهدف والمدة. 2. اكتب افتتاحية جذابة، 3 مشاهد، وخاتمة واضحة. 3. اختر صورًا أو مقاطع مرخصة. 4. اضبط 9:16 للمقاطع العمودية أو 16:9 للأفقية. 5. أضف تعليقًا عربيًا وترجمة مقروءة. 6. صدّر واختبر العرض على الهاتف قبل النشر.
أريد مونتاجًا احترافيًا لمقاطع موجودة+
يمكن اختبار تجميع المقاطع وإضافة التعليق والترجمة، لكن لا يوجد دليل حتى الآن على خط زمني متعدد المسارات أو قص دقيق أو مؤثرات تحرير احترافية. للمونتاج الدقيق استخدم محرر فيديو مخصص، ثم أعد إدخال النتيجة عند الحاجة.
كيف أختبر كل مسار وأوثق النتيجة؟+
نفّذ تجربة 10–20 ثانية بملفات غير حساسة. سجّل: نوع المدخل، الإعدادات، هل بدأ الإنتاج، هل خرج MP4، جودة الصوت، جودة الترجمة، المدة، الأخطاء، وهل استُخدمت خدمة خارجية. صنّف النتيجة: نجح / نجح جزئيًا / لم يعمل / لم يُختبر.
متى أحتاج GitHub أو قاعدة بيانات؟+
بعد نجاح إنتاج فيديو واحد على الأقل: استخدم GitHub لحفظ الشيفرة والوثائق والتعديلات، وليس لمعالجة الفيديو على GitHub Pages. أضف قاعدة بيانات عند الحاجة إلى سجل مشاريع ومستخدمين وحالات مهام؛ ولا تضع مفاتيح API أو فيديوهات خاصة في مستودع عام.
خريطة القرار السريعة+
صورة واحدة ← مسار صورة + تعليق. صور عديدة ← مسار قصة مصورة. فيديو جاهز ← اختبار استيراد + ترجمة. أغنية ← تحقق من دعم الصوت والترخيص أو استخدم محررًا خارجيًا. صورة ناطقة ← أداة مزامنة شفاه خارجية. إنتاج جماعي ← اختبر محليًا أولًا ثم خطط للتخزين وقاعدة البيانات.

موسوعة المشروع / تطبيقات الإنتاج

ماذا نستطيع أن ننتج بهذه المنصة؟

دليل تطبيقي من أول صورة إلى فيديو متعدد المشاهد، مع فصل الوظائف المثبتة عن المقترحة.

1 — ما أنواع الفيديو التي نستطيع إنتاجها؟+
فيديو شرح فكرة أو قصة قصيرة: نص تعليق صوتي + صور/مقاطع + ترجمة. فيديو توعوي أو تعليمي، عرض صور لمنتج، فيديو عمودي 9:16 أو أفقي 16:9، وفيديو متعدد المشاهد. هذه مسارات إنتاج محتملة بحسب إعدادات الواجهة؛ نجاح كل مسار يجب اختباره فعليًا.
2 — تجربة أول فيديو من صورة واحدة+
1) اكتب وصف الفكرة أو نص التعليق بنفسك. 2) اختر «ملف محلي من جهازك». 3) ارفع صورة تملك حق استخدامها. 4) اختر «احتواء بخلفية سوداء» أو ملاءمة مناسبة. 5) اختر حركة «تكبير بطيء» إن رغبت. 6) اختر صوتًا عربيًا متاحًا، ومقاس الفيديو، والترجمة. 7) ابدأ إنشاء مقطع قصير ثم راجع الصوت والمدة والتصدير. النتيجة المتوقعة: صورة ثابتة أو ذات حركة كاميرا مع تعليق؛ ليست صورة تتكلم بتحريك الشفتين.
3 — من صورة إلى شخصية تتحدث+
إذا كان المقصود أن يتحرك وجه الشخص وتُزامَن الشفاه مع الصوت، فهذا «Talking Photo / Lip Sync» وليس مجرد تحريك الصورة أو إضافة تعليق. لم يثبت من الواجهة أن هذه الوظيفة مدمجة؛ قد تتطلب أداة أفاتار خارجية ثم استيراد الفيديو الناتج.
4 — من مجموعة صور إلى فيديو أو قصة+
جهّز الصور بالترتيب وأسماء واضحة (01، 02، 03). جرّب رفع عدة صور إن سمح حقل الرفع بذلك، ثم اختر طريقة ترتيب المقاطع والانتقال والحركة. ضع تعليقًا مناسبًا لكل لقطة، وراجع توزيع مدة الصور. إن لم تقبل الواجهة عدة ملفات أو لم تحفظ ترتيبها، أنشئ المقاطع منفصلة أو استخدم محرر فيديو خارجي للتجميع. لا نفترض دعم دفعات الصور دون تجربة.
5 — رفع فيديو موجود: ما الذي يمكن عمله؟+
الواجهة تعرض رفع MP4 وMOV وAVI وFLV وMKV وغيرها مع حد ظاهر 200MB لكل ملف. هذا يؤكد وجود مسار إدخال فيديو، لا يثبت أنه محرر مونتاج كامل. جرّب مقطعًا قصيرًا لاختبار استخدامه خلفيةً مع تعليق وترجمة، ثم تحقق من القص، الدمج، والتحكم بالصوت؛ هذه القدرات ليست مؤكدة من الصور.
6 — المونتاج والقص والدمج والانتقالات+
تظهر إعدادات «طريقة ترتيب المقاطع» و«الانتقال بين اللقطات»، ما يشير إلى إمكانات تجميع آلي. لكن وجود خط زمني يدوي، قص إطار محدد، طبقات متعددة، تصحيح ألوان، وإزالة الصوت الأصلي غير مثبت. للمونتاج الدقيق قد نحتاج CapCut أو DaVinci Resolve أو FFmpeg بعد التصدير.
7 — إضافة تعليق صوتي عربي+
اكتب نص التعليق في حقل «نص التعليق الصوتي»، واختر اللغة والصوت/محرك تحويل النص إلى كلام من الإعدادات المتاحة. جرّب جملة قصيرة أولًا؛ قد تحتاج بعض المحركات إلى تنزيل نموذج أو خدمة خارجية. افحص التشكيل، أسماء الأعلام، نطق الأرقام، ومواءمة زمن الصوت مع الصور.
8 — الموسيقى والأغاني والمؤثرات+
يمكن نظريًا وضع موسيقى خلفية أو أغنية ضمن مسار مونتاج، لكن لم نتحقق من وجود حقل موسيقى مدمج في النسخة المعروضة. افحص أسفل الصفحة وإعدادات الصوت؛ إن لم يوجد، أضف الموسيقى بعد تصدير الفيديو في محرر خارجي. استخدم ملفات تملك حقوقها أو ترخيصًا يسمح بالاستخدام والنشر؛ وجود أغنية على الإنترنت لا يعني جواز إدراجها في فيديو منشور.
9 — الصوت الأصلي للفيديو وموازنة المستويات+
إذا رفعت فيديو به صوت، اختبر هل تحتفظ المنصة بالصوت الأصلي أو تستبدله أو تمزجه مع التعليق. لا تفترض التحكم بمستوى كل مسار دون التأكد. يُفضّل خفض موسيقى الخلفية تحت الكلام، وتجربة سماع الفيديو بالهاتف والسماعات.
10 — الترجمة العربية على الشاشة+
فعّل «إظهار النص على الفيديو»، ثم اختر الخط والموضع والحجم واللون والخلفية والشفافية من اللوحة اليمنى. اختبر عرض الحروف واتجاه RTL والتزامن وعدم قطع السطور. خط الترجمة الظاهر STHeitiMedium.ttc ليس خط أميري؛ خط الموسوعة لا يغيّر خط الترجمة تلقائيًا.
11 — صور المنتجات والإعلانات القصيرة+
مثال: ثلاث صور لمنتج، عنوان افتتاحي، ثلاث فوائد مثبتة، دعوة ختامية، تعليق صوتي عربي وموسيقى مرخّصة. يمكن أن ينتج إعلانًا بسيطًا إذا نجح رفع الصور وتجميعها. تجنّب ادعاءات تسويقية غير موثقة، ولا تخلط بين إنشاء الإعلان تلقائيًا وبين تحريره باحتراف.
12 — الفيديو التعليمي والتوعوي+
قسّم الموضوع إلى افتتاحية، ثلاثة مشاهد توضيحية، وخاتمة. اكتب نصًا قصيرًا لكل مشهد، واختر صورًا مناسبة وتعليقًا واضحًا وترجمة كبيرة. مثال: فقرة «الإنقاذ الذي ينقلب خطرًا» باستخدام صور متتابعة، مع التحقق من وضوح العلاقة السببية في المشهد.
13 — مصادر الصور والفيديو ومفاتيح API+
تظهر إعدادات Pexels وPixabay وCoverr، وهي مصادر محتملة لجلب الوسائط؛ تحتاج بعض المسارات إلى مفاتيح API واتصال بالإنترنت وقد تختلف التراخيص. الرفع المحلي هو الأفضل للتجربة الأولى. لا تضع مفاتيحك السرية في GitHub أو ملفات عامة.
14 — ما المتطلبات قبل الإنتاج؟+
تشغيل Python والبيئة الافتراضية، تثبيت requirements.txt، توافر FFmpeg عند الحاجة، مساحة تخزين مناسبة، اتصال بالإنترنت للمصادر أو خدمات الصوت السحابية، واختبار أن التطبيق يفتح على localhost:8501. نجح تثبيت المتطلبات وفحص pip check في التجربة المصورة، لكن لم نتحقق من اكتمال تصدير فيديو.
15 — هل نحتاج OpenAI أو خدمة مدفوعة؟+
تظهر OpenAI كمزود اختياري للنص في الإعدادات، وحقل مفتاح API فارغ. لا تضع مفتاحًا مدفوعًا ولا تفعّل خدمة إلا بموافقة صريحة. يمكن البدء بنص مكتوب يدويًا ووسائط محلية لتقليل التكلفة، لكن توافر توليد الصوت محليًا يعتمد على المحرك المختار.
16 — ماذا عن GitHub وقاعدة البيانات؟+
GitHub مناسب لحفظ الشيفرة والإصدارات والوثائق، وليس لتشغيل معالجة فيديو ثقيلة على GitHub Pages. قاعدة بيانات مثل Supabase يمكن أن تحفظ بيانات المشاريع والمهام والنتائج، بينما تحفظ ملفات الفيديو الكبيرة في تخزين كائني مناسب. كلا الربطين مشروع تطوير منفصل، غير مفعّل حاليًا.
17 — خطة اختبار منظمة: ست تجارب+
1) صورة واحدة + تعليق عربي. 2) صورتان أو أكثر + انتقال. 3) فيديو محلي + تعليق وترجمة. 4) موسيقى خلفية إن كانت مدعومة. 5) فيديو عمودي 9:16. 6) تصدير ومراجعة ملف MP4. لكل تجربة سجّل: المدخلات، الإعدادات، النتيجة، الزمن، الأخطاء، والتكلفة. لا نعتبر الوظيفة مؤكدة إلا بعد نجاح الاختبار.
18 — مصفوفة الدعم: المؤكد والمشروط وغير المثبت+
مؤكد من الصور: تشغيل الواجهة، رفع وسائط محلية بصيغ متعددة، إعدادات نص وتعليق وترجمة وحركة وترتيب وانتقالات، خيارات أبعاد الفيديو. مشروط بالاختبار: إنتاج فيديو كامل من صورة أو صور، الحفاظ على صوت الفيديو، المزج، نجاح التصدير. غير مثبت: تحريك شفاه صورة، مونتاج زمني احترافي، إضافة أغنية من رابط، الربط المباشر بـ GitHub أو قاعدة بيانات.

الربط مع GitHub

هل يمكن ربطه؟+
نعم، يمكن حفظ الشيفرة وتتبع الإصدارات على GitHub. لكن رفع الملفات إلى GitHub لا يشغّل تلقائيًا تطبيق Python/Streamlit كخادم.

قواعد البيانات

اضغط على أي عنوان لقراءة التفاصيل، ويمكنك فتح جميع الفروع أو إغلاقها.

هل يحتاج قاعدة بيانات الآن؟+
ليس بالضرورة لإنتاج فيديو تجريبي محلي. قاعدة البيانات تصبح مفيدة عند إدارة مشاريع متعددة ومستخدمين وعمليات إنتاج.
ما الذي يمكن تخزينه؟+
عناوين المشاريع، نصوص الفيديو، حالة المهام، الإعدادات غير السرية، روابط الملفات، وسجل الإصدارات.
أين تُحفظ ملفات الفيديو؟+
عادةً في تخزين ملفات/كائنات، مع حفظ المسارات والبيانات الوصفية في قاعدة البيانات، وليس وضع ملفات الفيديو الكبيرة داخل الجداول مباشرة.
SQLite أم Supabase؟+
SQLite مناسبة لبداية محلية بسيطة. Supabase/PostgreSQL أنسب عند الحاجة إلى حسابات ومزامنة وتعاون وتخزين سحابي، مع مراعاة التكاليف وسياسات الوصول.
ضوابط مهمة+
مصادقة، صلاحيات، سياسات وصول للبيانات، نسخ احتياطية، وحدود لحجم الملفات والتكاليف. الربط المقترح لم يُنفذ بعد.
الموسوعة / مواصفات التطوير

استوديو حين تنطق الصور — الرؤية الشاملة وخطة التنفيذ

هذه وثيقة متطلبات قابلة للتسليم إلى مطوّر. تفصل بين الموجود فعليًا والوظائف المطلوبة مستقبلًا، ولا تُنشئ تكاملات مدفوعة من تلقاء نفسها.

الرؤية المعتمدة: استوديو متعدد المسارات+
نحوّل «حين تنطق الصور» إلى واجهة عربية تجمع إنشاء السيناريو والصور والصوت والمقاطع والتحريك ومزامنة الشفاه والمونتاج والتصدير. الأولوية للإنتاج المحلي أو المجاني، مع خيارات مدفوعة اختيارية لا تُستدعى إلا بموافقة واضحة. لا نعد المستخدم بأن كل مزود متصل بالفعل.
اختر المهمة قبل اختيار الأداة+
المسارات: صور ثابتة إلى فيديو؛ قصة كرتونية متعددة الشخصيات؛ صورة تتكلم؛ أفاتار ناطق؛ مقاطع فيديو إلى مونتاج؛ تعليق صوتي فقط؛ موسيقى أو أغنية؛ فيديو تعليمي أو إعلان؛ ترجمة ودبلجة. تعرض الواجهة لكل مسار: المدخلات المطلوبة، خطوات التنفيذ، المدة، التكلفة التقريبية إن أمكن التحقق منها، حالة دعم الميزة، والبدائل.
المحرك المجاني أولًا+
احتفظ بوظائف الرفع المحلي وترتيب الصور والتحريك البسيط والموسيقى والتعليق والترجمة والتصدير. أضف معاينة صوت مستقلة بمشغّل وإعادة استخدام ملف الصوت المعتمد، ومعاينة نص/ترجمة قبل التصيير، وحفظ إعدادات المشروع. «مجاني» لا يعني أن أي خدمة سحابية خارجية مجانية.
مكتبة مزودي الصوت+
خيارات محتملة: المحرك الصوتي الموجود حاليًا Azure TTS V1، رفع MP3/WAV، ومحركات أخرى بعد التحقق من التكامل والترخيص. يختار المستخدم اللغة والصوت والسرعة والنبرة، ويستمع إلى مقطع أو النص كله قبل التصيير. يجب فصل اشتراك موقع الخدمة عن صلاحية API الخاصة بها، وحظر أي استدعاء مدفوع تلقائي.
تحريك الصور ومزامنة الشفاه+
هناك فرق بين حركة كاميرا بسيطة على صورة ثابتة، وتحويل الصورة إلى مقطع متحرك، وتحريك شفاه شخصية تتكلم. مسار العمل: صورة شخصية متسقة → نص وصوت معتمدان → اختيار محرك حركة/شفاه → توليد لقطة → معاينة → إضافة اللقطة إلى الخط الزمني. يمكن استخدام خدمات خارجية يدويًا أولًا، ثم تكامل آلي فقط إن كان موثقًا ومتاحًا.
Flow وGemini وOpenAI وخدمات أخرى+
تُعرض بوصفها مزودين محتملين للصور/الفيديو/النص/الصوت بحسب قدرات كل خدمة وقت التنفيذ. لا نفترض أن اشتراك الويب يشمل API أو يسمح بالربط المباشر. ننشئ «بطاقة مزود» تتضمن رابط الخدمة الرسمي، نوع المخرجات، طريقة الاستيراد، توافر API المؤكد، التكلفة، القيود، والحقوق. الروابط الرسمية العامة: https://labs.google/fx/tools/flow و https://ai.google.dev/ و https://platform.openai.com/docs .
الأفاتار والشخصيات الكرتونية المتسقة+
مكتبة شخصيات تحفظ وصف الشكل والملابس والسن والصوت ومراجع الصور المصرّح بها. لكل قصة: ملف شخصية، قائمة مشاهد، صورة لكل مشهد، حوار كل شخصية، صوت مستقل، حركات، ومزامنة شفاه عند توافر المحرك. يجب اختبار ثبات الوجه بين الأعمار والمشاهد؛ لا يكفي البرومبت وحده لضمان التطابق.
المونتاج والكتابة والخطوط+
خط زمني للمشاهد مع سحب وإفلات، قص ودمج، تغيير المدة لكل صورة، انتقالات، مستويات صوت متعددة، موسيقى خاصة، ضبط نسب 16:9 و9:16، طبقات نص، خطوط عربية بينها Amiri، واتجاه RTL. يجب إصلاح تشكيل العربية وربط حروفها في محرك تصدير الترجمة لا الاكتفاء بتغيير قائمة الخطوط.
معاينة الصوت قبل الفيديو+
زر «توليد معاينة الصوت» مع مشغّل داخل الواجهة (تشغيل/إيقاف/تقديم/إعادة). خيار تجربة جملة محددة، وتصحيح التشكيل، وحفظ نسخة MP3/WAV، واعتماد الصوت لاستخدامه في التصدير دون إعادة توليد. يجب ألا يبدأ توليد فيديو عند الضغط على معاينة الصوت.
الموسيقى والأغاني+
رفع ملف صوت مرخّص MP3/WAV أو اختيار موسيقى مدمجة أو إنتاج أغنية في خدمة خارجية ثم استيرادها. تُعرض معلومات الحقوق ونوع الترخيص ومستوى الصوت وخفض الموسيقى أثناء الحوار. الربط المباشر بخدمة أغاني لا يُفعّل قبل التحقق من واجهة التكامل وشروط الاشتراك.
التكاليف والمفاتيح والخصوصية+
لوحة اختيار «محلي/مجاني/مدفوع» مع إظهار تنبيه قبل أي عملية مدفوعة وتقدير تكلفة إذا كانت معلومة من المزود. لا تحفظ المفاتيح داخل HTML أو GitHub، ولا ترسل الصور الخاصة إلى مزود خارجي دون اختيار المستخدم. سجّل حالة كل مهمة واسم المزود ونتيجتها دون كشف الأسرار.
البنية المقترحة والتدرج+
المرحلة 0: نسخ احتياطي وجرد الشيفرة والاختبارات. المرحلة 1: إصلاح ترجمة العربية ومعاينة الصوت. المرحلة 2: إدارة المشروعات وترتيب المشاهد ومددها وموسيقاها. المرحلة 3: تكامل مزود واحد اختياري بصيغة موحدة. المرحلة 4: صور ناطقة/أفاتار/تحريك مع تجربة محدودة. المرحلة 5: حسابات وقاعدة بيانات وتخزين إن ظهرت حاجة حقيقية. كل مرحلة في فرع منفصل مع اختبارات قبل الدمج.
طريقة تعاون ChatGPT وClaude مع البرنامج المحلي+
لا يتطلب البرنامج المحلي نشره على موقع عام. يمكن العمل على ملفات المشروع مباشرة عبر أدوات برمجة لديها صلاحية الوصول إلى المجلد أو المستودع؛ مجرد فتح ChatGPT في Chrome لا يمنحه صلاحية تحرير ملفات Windows. يمكن استخدام GitHub مستودعًا خاصًا ومزامنة الفروع، أو بيئة Work/Computer Use حين تكون متاحة وموصولة بالجهاز. لا تُفتح منافذ localhost للعامة ولا تُرفع مفاتيح API.
مواصفات قبول أول إصدار مطور+
نجاح: رفع 5 صور بالترتيب، فيديو أفقي، صوت عربي مسموع في المعاينة، تصحيح كلمة وإعادة المعاينة فقط، ترجمة Amiri عربية متصلة بلا مربعات، موسيقى خلفية مرخّصة، تصدير MP4، وعدم تشغيل خدمة مدفوعة بلا موافقة. إضافة اختبار استيراد فيديو وصوت جاهز دون كسر المسار الحالي.
رسالة تسليم العمل إلى Claude+
الملف نفسه وثيقة المتطلبات. قبل تعديل البرنامج: افحص المستودع وملفات الصوت/الترجمة/الواجهة، قدّم جدول «موجود/غير موجود/يحتاج تعديل»، وخطة تنفيذ على مراحل. احتفظ بنسخة احتياطية واعمل في فرع منفصل، ولا تغيّر المسارات الناجحة، ولا تشغّل API مدفوعًا، واختبر الترجمة العربية ومعاينة الصوت ثم اعرض الفروقات قبل الدمج.
