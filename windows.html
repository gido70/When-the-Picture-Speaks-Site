تشغيل الاستوديو على Windows

لأي جهاز، جديدًا كان أو قديمًا: أمران تنسخونهما في PowerShell مرة واحدة فقط. بعدها اختصار على سطح المكتب يفتح الاستوديو مباشرة.

🔄 تحديث الاستوديو📖 الدليل☁️ Google Drive☁️ OneDrive📁 مجلد ملفات Windows في GitHub

🔄 تحديث الاستوديو إلى آخر إصدار آخر إصدار: 1.12.0-capcut-tools

الطريقة الأسهل (من الإصدار 1.7.2): داخل الاستوديو، في أعلى القائمة الجانبية: عند ظهور «🆕 يوجد تحديث جديد» اضغطوا «🔄 تحديث الآن». تختفي الصفحة لحظات ثم تعود وحدها بالإصدار الجديد.

أو اختصار «تحديث حين تنطق الصورة» على سطح المكتب. يوقف الاستوديو القديم، ويجلب الجديد من GitHub، ويفحصه، ثم يفتحه وحده.

أو انسخوا هذا الأمر إلى PowerShell، وهو يفعل الشيء نفسه (مفيد أيضًا إن كانت أداة التحديث على جهازكم قديمة):

Get-NetTCPConnection -LocalPort 8510 -State Listen -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }; cd C:\WhenThePictureSpeaks\studio; git pull --ff-only origin main; git log -1 --oneline; Start-Process wscript.exe C:\WhenThePictureSpeaks\studio\windows\Launch-Studio.vbs

بعد التحديث تأكدوا من سطر «إصدار الاستوديو» أعلى الصفحة الرئيسية. إن ظهر رقم قديم فالاستوديو القديم ما زال يعمل: أعيدوا تشغيل الجهاز ثم افتحوا الاختصار. مشاريعكم وفيديوهاتكم وإعداداتكم لا يمسها أي تحديث.

☁️ المزامنة عبر Google Drive (بدل OneDrive)

شرط مهم: في تطبيق Google Drive على الجهازين: الإعدادات ← Google Drive ← اختاروا «Mirror files» (نسخ الملفات) لا «Stream files». في وضع Stream يظهر Drive كقرص افتراضي (G:)، والوصلة قد لا تعمل عليه. في وضع Mirror يصبح المجلد حقيقيًا: C:\Users\اسمك\My Drive.

الجهاز الأول (الذي فيه المشاريع)

  1. أغلقوا الاستوديو، ثم الصقوا في PowerShell:
Move-Item C:\WhenThePictureSpeaks\projects "$env:USERPROFILE\My Drive\WhenThePictureSpeaks-projects"; cmd /c mklink /J C:\WhenThePictureSpeaks\projects "$env:USERPROFILE\My Drive\WhenThePictureSpeaks-projects"
  1. انتظروا حتى يُكمل Google Drive الرفع.

الجهاز الثاني

  1. انتظروا حتى يظهر المجلد WhenThePictureSpeaks-projects داخل My Drive، ثم أغلقوا الاستوديو والصقوا:
Rename-Item C:\WhenThePictureSpeaks\projects projects-old; cmd /c mklink /J C:\WhenThePictureSpeaks\projects "$env:USERPROFILE\My Drive\WhenThePictureSpeaks-projects"

للتحقق على أي جهاز

cmd /c dir C:\WhenThePictureSpeaks | findstr /i "projects"

يجب أن يظهر <JUNCTION> projects [...My Drive\WhenThePictureSpeaks-projects]. إن ظهر <DIR> فقط فالمجلد نسخة محلية غير مزامنة.

إن كنتم قد نفّذتم خطوات OneDrive سابقًا، فلا تجمعوا بين الخدمتين: اختاروا واحدة. لا تفتحوا المشروع نفسه على الجهازين معًا. هذه الطريقة لم تُختبر بعد على أجهزتكم؛ أرسلوا نتيجة أمر التحقق.

☁️ مزامنة المشاريع بين جهازين (OneDrive) مرة واحدة لكل جهاز

بدونها يحفظ كل جهاز مشاريعه وحده. بعدها يظهر أي تعديل على الجهاز الآخر تلقائيًا.

الجهاز الأول (الذي فيه المشاريع)

  1. أغلقوا الاستوديو.
  2. الصقوا هذا الأمر في PowerShell:
Move-Item C:\WhenThePictureSpeaks\projects "$env:OneDrive\WhenThePictureSpeaks-projects"; cmd /c mklink /J C:\WhenThePictureSpeaks\projects "$env:OneDrive\WhenThePictureSpeaks-projects"
  1. انتظروا علامة ✓ الخضراء على مجلد WhenThePictureSpeaks-projects في OneDrive.

الجهاز الثاني (اللابتوب)

  1. أغلقوا الاستوديو، وتأكدوا أن OneDrive نزّل المجلد WhenThePictureSpeaks-projects.
  2. الصقوا هذا الأمر في PowerShell:
Rename-Item C:\WhenThePictureSpeaks\projects projects-old; cmd /c mklink /J C:\WhenThePictureSpeaks\projects "$env:OneDrive\WhenThePictureSpeaks-projects"

لا تفتحوا المشروع نفسه على الجهازين في الوقت نفسه · انتظروا انتهاء مزامنة OneDrive قبل فتح الاستوديو على الجهاز الآخر · OneDrive المجاني 5 غيغابايت فقط. المجلد القديم في اللابتوب يبقى باسم projects-old للاحتياط.

🖥️ قبل البدء: فتح PowerShell

  1. اضغطوا زر Start (شعار Windows) أسفل الشاشة.
  2. اكتبوا PowerShell، ثم اضغطوا على Windows PowerShell. تفتح نافذة سوداء أو زرقاء.
  3. لكل خطوة: اضغطوا زر «نسخ» بجانب الأمر، ثم الصقوه في النافذة بزر الفأرة الأيمن، واضغطوا Enter.

لماذا الأوامر وليس الملفات؟ حماية Windows 11 المسماة Smart App Control تمنع تشغيل الملفات المنزّلة من نوع .cmd. الأوامر المنسوخة تعمل دائمًا، وتفعل الشيء نفسه بالضبط.

١ تثبيت برنامج Git مرة واحدة لكل جهاز

winget install --id Git.Git -e --source winget
  1. انتظروا حتى ينتهي التثبيت (نحو دقيقة).
  2. أغلقوا نافذة PowerShell وافتحوا نافذة جديدة، حتى يتعرف Windows على Git.
  3. للتأكد، الصقوا هذا الأمر في النافذة الجديدة. يجب أن يظهر رقم إصدار مثل git version 2.56.0:
git --version

بديل: تنزيل ملف التثبيت (قد تمنعه حماية Windows)، أو تنزيل Git من موقعه الرسمي.

٢ تثبيت الاستوديو مرة واحدة لكل جهاز

أمر واحد ينزّل الاستوديو ويثبّت كل شيء، ومنه Python 3.11 إن لم يكن موجودًا:

git clone -b main https://github.com/gido70/When-the-Picture-Speaks.git C:\WhenThePictureSpeaks\studio; if ($?) { powershell -NoProfile -ExecutionPolicy Bypass -File C:\WhenThePictureSpeaks\studio\windows\install.ps1 }
  1. تفتح نافذة دخول GitHub في المتصفح: ادخلوا بحسابكم واضغطوا Authorize. تظهر بعدها صفحة Authentication Succeeded؛ أغلقوها وارجعوا إلى النافذة السوداء.
  2. تظهر ست مراحل بعناوين زرقاء: == 1/6 Python 3.11 حتى == 6/6 Starting the studio. مرحلة المكتبات (2/6) أطولها؛ لا تغلقوا النافذة.
  3. عند ظهور DONE باللون الأخضر، يفتح الاستوديو في المتصفح.

على الجهاز الذي فيه نسخة قديمة تُنقل الإعدادات تلقائيًا. على جهاز جديد تبدأ الإعدادات الافتراضية، والمسار المجاني (صوت Edge والمزامنة والتصدير) يعمل دون مفاتيح. لنقل مفاتيح المزودين: انسخوا ملف config.toml من C:\WhenThePictureSpeaks\studio في الجهاز الأول إلى المكان نفسه في الجهاز الجديد.

بديل: تنزيل ملف التثبيت (قد تمنعه حماية Windows).

٣ الاستعمال اليومي بضغطة واحدة

بعد التثبيت تجدون على سطح المكتب ثلاثة اختصارات، ولا حاجة إلى PowerShell بعدها:

  • «حين تنطق الصورة»: يفتح الاستوديو في المتصفح مباشرة، دون نافذة سوداء.
  • «تحديث حين تنطق الصورة»: يجلب آخر نسخة معتمدة من GitHub، ويرجع تلقائيًا إلى السابقة إن فشل شيء.
  • «مجلد حين تنطق الصورة»: يفتح مجلد البرنامج والمشاريع.

الاستوديو الرسمي يعمل على http://localhost:8510، فلا يختلط بالنسخ القديمة (8501). وفي أعلى الاستوديو سطر يعرض رقم الإصدار والمجلد للتأكد.

🛠️ عند المشكلات

  • الاختصارات غير موجودة، أو التثبيت توقف في منتصفه: أعيدوا أمر الخطوة ٢. إن ظهر أن المجلد موجود، الصقوا هذا الأمر بدلًا منه لإكمال التثبيت دون تنزيل جديد:
powershell -NoProfile -ExecutionPolicy Bypass -File C:\WhenThePictureSpeaks\studio\windows\install.ps1
  • الاستوديو لا يفتح: افتحوا «مجلد حين تنطق الصورة»، ثم studio\windows، وشغّلوا Start-Studio-Debug.cmd. تظهر نافذة بالخطأ؛ أرسلوا صورتها. (ملفات هذا المجلد لا تمنعها حماية Windows لأنها لم تُنزَّل من المتصفح.)
  • لإيقاف الاستوديو العامل في الخلفية: studio\windows\Stop-Studio.cmd.

المكان الثابت على جهازكم (بعد الخطوة ٢)

C:\WhenThePictureSpeaks\studio ← البرنامج، ويُحدَّث من GitHub
C:\WhenThePictureSpeaks\projects ← مشاريعكم وفيديوهاتكم، ولا يمسها أي تحديث

النسخ القديمة في مجلد التنزيلات تبقى كما هي، ولا يُحذف شيء دون قراركم. أدوات إضافية في مجلد GitHub: إيقاف الاستوديو، وتشغيله بنافذة ظاهرة لتشخيص أي مشكلة. ورابط «مجلد ملفات Windows في GitHub» يفتح بعد الدخول بحسابكم، لأن مستودع البرنامج خاص.
